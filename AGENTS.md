# 14. PERFORMANCE

Premium does not mean slow.

Target:

- fast initial render
- optimized images
- lazy-loaded heavy media
- minimal JavaScript where possible
- code splitting
- GPU-friendly transforms
- avoid layout thrashing
- avoid unnecessary React renders
- avoid massive WebGL scenes
- avoid unnecessary animation loops

Use:

transform
opacity

for most animation.

Avoid animating:

top
left
width
height

when transform-based alternatives exist.
